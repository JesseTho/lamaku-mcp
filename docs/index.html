lamaku-mcp

Build your Lamakū courses by describing them. Tell your AI assistant what you want in a module and it creates the pages, uploads the video, and sets up the discussion and the assignment. You see every change before it is made.

How to install

git clone https://github.com/JesseTho/lamaku-mcp
cd lamaku-mcp && pnpm install && pnpm build
node dist/cli.js login
claude mcp add lamaku -- node "$PWD/dist/index.js"

You will need Node.js 20 or later, your usual Lamakū login, and an assistant that can use outside tools, such as Claude Code. Signing in opens a browser for UH login and Duo. Try it on a sandbox course first: deletes cannot be undone.

Features

  • Reads the courses you already teach, so you can ask what is in them
  • Creates content modules and pages
  • Uploads video, images and PDFs
  • Sets up assignments, grade items, discussions, announcements and checklists
  • Imports a course package, which is how quizzes and rubrics come across
  • Shows you every change first, and adds it hidden from students

It cannot build quiz questions or rubrics on its own, and it does not enter grades. The full list of limits says what to do instead.

FERPA guard

Student names, usernames and email addresses do not leave Lamakū. Before any course data goes to the assistant, each student is swapped for an anonymous label such as student:4f2a91. The label stays the same throughout, so you can still ask about the student who missed the third lab without naming anyone.

On by default. Co-instructors are not anonymised, and you can ask for real names when you need them.
