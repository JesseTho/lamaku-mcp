lamaku-mcp

An MCP server for Lamakū, the University of Hawaiʻi's D2L Brightspace instance. Describe a module to your AI assistant and it builds the module in your course.

git clone https://github.com/JesseTho/lamaku-mcp
cd lamaku-mcp && pnpm install && pnpm build
node dist/cli.js login
claude mcp add lamaku -- node "$PWD/dist/index.js"

Needs Node 20 or later, a Lamakū account, and an MCP client. Signing in opens a browser for UH SSO. Point it at a sandbox course first.

What it does

  • Reads your courses: modules, files, assignments, grades, discussions, quizzes
  • Writes content modules and authored HTML pages
  • Uploads video, images and PDFs into the course
  • Creates assignments, grade items, discussions, announcements, checklists
  • Imports a whole course package, which is how quizzes and rubrics get in
  • Previews every write before it happens, and withholds student names by default

It cannot write quiz questions directly, author rubrics, or set grade values. The limits are listed in full, with what to do instead.
