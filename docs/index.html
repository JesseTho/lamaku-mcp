How to install

npx -y lamaku-mcp login

Then register it with your assistant:

Claude Code 
claude mcp add lamaku -- npx -y lamaku-mcp
Codex CLI 
codex mcp add lamaku -- npx -y lamaku-mcp
Gemini CLI 
gemini mcp add lamaku npx -y lamaku-mcp

Features

  • Reads your courses
  • Creates content modules and pages
  • Uploads video, images and PDFs
  • Sets up assignments, grade items, discussions and checklists
  • Imports whole course packages
  • Previews every change before it happens
  • FERPA guard: prevents student data leaking to LLMs
