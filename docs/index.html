How to install

git clone https://github.com/JesseTho/lamaku-mcp
cd lamaku-mcp && pnpm install && pnpm build
node dist/cli.js login
claude mcp add lamaku -- node "$PWD/dist/index.js"

Needs Node.js 20+ and an MCP client. Setting up from scratch.

Features

  • Reads the courses you already teach
  • Creates content modules and pages
  • Uploads video, images and PDFs
  • Sets up assignments, grade items, discussions and checklists
  • Imports course packages, including quizzes and rubrics
  • Shows every change before it is made, and adds it hidden
  • FERPA guard: prevents student data leaking to LLMs

Quizzes and rubrics arrive through a course package rather than one at a time. Grades it does not enter at all. Full list of limits.
